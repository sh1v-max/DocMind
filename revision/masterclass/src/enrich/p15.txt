@Q 15.1

@Q 15.2
S: LangGraph models an application as a state machine graph: a typed state object, nodes (functions or agents) that read and update the state, and edges (including conditional and cyclic edges) that decide the next node. A checkpointer persists state after each step, enabling resume, time travel, and human-in-the-loop via interrupts. It’s used for complex agents (loops with tool calls, multi-agent supervisors) where control flow must be explicit.
E: An agent graph: “call_model” → conditional edge (tool calls? → “tools” → back to “call_model” : END).
Q: How is a LangGraph interrupt similar to Mastra suspend?
A: Both pause execution at a point, persist state, and resume later with human input.
N: “LangGraph is a graph database.”
@Q 15.3
E: LangChain: “retrieve then answer” chain. LangGraph: “route → maybe search (loop) → maybe ask human → answer” with persisted state.
N: “LangGraph replaces LangChain entirely.”
@Q 15.4

@Q 15.5
S: Orchestration frameworks coordinate the moving parts of LLM applications: they define steps or graphs, pass state between them, call models and tools, handle loops and branching, persist progress, retry failures, pause for humans, and record traces. Examples: Mastra, LangGraph, LlamaIndex workflows, Temporal or Inngest used with LLM steps.

A: Not by itself; queues execute independent jobs. Orchestration adds multi-step state and control flow on top.

@Q 15.7
S: Multi-agent systems split work among specialised agents (researcher, writer, critic; or per-domain agents) coordinated by a supervisor agent that delegates (agents as tools), by a workflow, or by peer messaging. Benefits: smaller focused prompts and tool sets, parallelism, separation of permissions. Costs: more calls, coordination failures, harder debugging.
E: Mastra supports supervisor agents with sub-agents exposed as tools; LangGraph and A2A support other patterns.
Q: When is multi-agent justified?
A: When tasks need clearly different tool sets or permissions, or when a single agent’s prompt becomes too large to manage; measure that it helps.

@Q 15.8
S: Each handoff loses context or introduces misinterpretation; errors compound; agents can loop delegating to each other; costs and latency multiply; it’s harder to know which agent caused a bad outcome; and permission boundaries blur if one agent can make another act. Mitigations: structured messages between agents, clear contracts, step and budget limits, tracing across agents, and least-privilege tools per agent.
E: A researcher agent summarises sources loosely; the writer agent treats the summary as fact and adds a wrong figure; no one checks.
Q: How do you debug a multi-agent failure?
A: A single trace across all agents with each message and tool call, so you can see where the information went wrong.
N: “Agents communicate perfectly in natural language.”

// a minimal MCP server (TypeScript SDK 1.32, stdio transport)
import { McpServer } from '@modelcontextprotocol/sdk/server/mcp.js';
import { StdioServerTransport } from '@modelcontextprotocol/sdk/server/stdio.js';
import { z } from 'zod';
const server = new McpServer({ name: 'docmind-search', version: '1.0.0' });
server.registerTool('search_documents', {
  title: 'Search documents',
  description: "Search the configured user's documents for passages relevant to a query.",
  inputSchema: { query: z.string().min(1).max(500) },              // a Zod raw shape
}, async ({ query }) => {
  const hits = await retrieve({ userId: process.env.DOCMIND_USER_ID, query, k: 5 });
  return { content: [{ type: 'text', text: hits.map((h) => `${h.filename}: ${h.content}`).join('\n---\n') }] };
});
await server.connect(new StdioServerTransport());

async function cachedAnswer(scopeKey, question, generate) {
  const qvec = await embed(question);
  const { rows } = await pool.query(
    `SELECT answer, 1 - (embedding <=> $2::vector) AS sim FROM answer_cache
     WHERE scope_key = $1 AND expires_at > now() ORDER BY embedding <=> $2::vector LIMIT 1`, [scopeKey, toVec(qvec)]);
  if (rows[0]?.sim >= 0.97) return { answer: rows[0].answer, cached: true };   // strict threshold
  const answer = await generate(question);
  await pool.query(`INSERT INTO answer_cache (scope_key, question, embedding, answer, expires_at)
                    VALUES ($1, $2, $3::vector, $4, now() + interval '1 day')`, [scopeKey, question, toVec(qvec), answer]);
  return { answer, cached: false };
}

import { trace } from '@opentelemetry/api';
const tracer = trace.getTracer('docmind');
async function tracedTool(name, args, fn) {
  return tracer.startActiveSpan(`tool ${name}`, async (span) => {
    span.setAttribute('tool.name', name);
    try { return await fn(args); }
    catch (e) { span.recordException(e); throw e; }
    finally { span.end(); }
  });
}
